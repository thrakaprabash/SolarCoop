# Epic 1 — Auth & Member Management

**Owner:** Shaveen K.K.I.  
**Sprint:** Sprint 1  
**Jira Work Items:** SOL-90, SOL-91, SOL-92, SOL-93, SOL-94, SOL-95  

## Scope

This epic covers authentication, member profiles, role-based access, and administrator member management for the Solar Co-op mobile application.

## Deliverables

- Master user flow covering registration, login, logout, profile, role-based access, and member management.
- Low-fidelity mobile wireframes for SOL-90 to SOL-95.
- Role-based access sitemap and access matrix.
- React Native implementation aligned with the UX designs.

## Design Principles

- Keep account creation short and clear.
- Validate essential household and grid-account information.
- Route users to navigation appropriate to their assigned role.
- Restrict member management features to administrators.
- Require confirmation before approving, blocking, or deactivating a member.

## Status

Design artefacts and implementation evidence will be added progressively during Sprint 1.
